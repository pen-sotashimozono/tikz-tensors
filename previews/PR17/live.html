Playground

Write a figure and see it drawn, by TeX running in this page: the package and the examples' notation (canl, center, gate, ...) are loaded, so a tikzpicture of the reference's commands is all a figure needs. Nothing is installed and nothing leaves your browser. The first drawing loads TeX into the page, a few megabytes; each one after it takes a few seconds.

Drawn by TikZJax (GPL-3.0-or-later), TeX compiled to WebAssembly, served unmodified; the pictures elsewhere on this site are the ones the tests check, drawn by LuaLaTeX.
