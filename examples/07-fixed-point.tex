% Fixed-point equations for a uniform MPS.
%
% Above: the transfer matrix. E is not drawn as a thing of its own, because it
% is not one -- it is the ket tensor A and its conjugate joined along the
% physical index. l carries two bond indices, one into each layer, which is why
% it is drawn tall rather than as a site: it lives in the doubled space. Solve
% l E = lambda l and an infinite chain has what it needs in place of an end.
%
% Below: the same column with the Hamiltonian's MPO tensor between the layers,
% so L carries three indices. The eigenvalue form is honest only block by block:
% an MPO for a local Hamiltonian is upper triangular with ones on the diagonal,
% so its transfer matrix has eigenvalue one with a Jordan block, and the block
% carrying the extensive part needs the energy per site subtracted and is a
% geometric sum rather than an eigenvector. The picture is the contraction, not
% the solver.
%
% The physical index leaves each triangle from the corner of its flat side, and
% the site is that side's line carried on down. W sits on that line because
% every tensor of a site does: the triangles are set across in their slots to
% put the corner there, and a box is centred on it. An earlier version of this
% file drew both conventions side by side to see where the MPO went; on a grid
% the question does not arise.
%
% Each right-hand side is a stack with no sites, the environment alone, whose
% indices end where the first site's tensors would be.
\documentclass[border=4pt]{standalone}
\usepackage{amsmath,amssymb}
\usepackage{tikz-tensors}
\input{notation}
\begin{document}
\begin{tikzpicture}
  \tnstack[left=$l$]{X}{1}{ket, bra}
  \tnlayer{X}{ket}{canl/$A$}
  \tnlayer{X}{bra}{canl/$\bar A$}
  \tnconnect{X}
  \tnopen{right}{X}
  \tneq[$\lambda$]
  \tnstack[left=$l$]{Y}{0}{ket, bra}
  \tnconnect{Y}
  \tnbreak
  \tnstack[left=$L$]{V}{1}{ket, op, bra}
  \tnlayer{V}{ket}{canl/$A$}
  \tnlayer{V}{op}{mpo/$W$}
  \tnlayer{V}{bra}{canl/$\bar A$}
  \tnconnect{V}
  \tnopen{right}{V}
  \tneq[$\lambda$]
  \tnstack[left=$L$]{U}{0}{ket, op, bra}
  \tnconnect{U}
\end{tikzpicture}
\end{document}
