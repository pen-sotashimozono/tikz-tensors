% The Trotter error is about the order the gates are applied in, and that is
% what these three pictures differ by.
%
% The nearest-neighbour terms of the Hamiltonian split into those on the odd
% bonds and those on the even ones. Within each half the gates commute, so each
% half is one layer; the two halves do not commute, so the layers have an order
% and the order shows.
%
% The first two are the same two layers in opposite orders. Each is correct to
% first order in dt and they are not equal to each other: the difference between
% them, O(dt^2) a step, is the first-order Trotter error. Read downward -- the
% layer nearest the state is applied first, so the operator product underneath
% each picture reads right to left as usual.
%
% The third is the symmetric arrangement, half a step of one half, a full step
% of the other, half a step of the first again. It is its own reverse, which is
% what kills the leading error term and leaves O(dt^3) a step. The price is one
% more layer of gates, which is the only thing the third picture has that the
% first two do not.
%
% The state is in a definite mixed canonical form throughout, because that is
% what makes the truncation after each gate cheap and controlled: with the
% orthogonality centre where it is, the singular values on the bond being cut
% are the Schmidt values, so discarding the smallest is the best rank-D
% approximation. Finite, so the chain stops; the outer bonds carry nothing.
%
% No gate has legs of its own. The physical indices run the whole way down and a
% gate is laid on the ones it acts on; a tensor is drawn over an index, so it
% interrupts them, which is what applying it means.
\documentclass[border=4pt]{standalone}
\usepackage{amsmath,amssymb}
\usepackage{tikz-tensors}

% one chain, in mixed canonical form, with its physical indices dropped #2
\newcommand{\tebdchain}[2]{%
  \tnchain{#1}{(0,0)}{(5,0)}{canl/$A$/l, canl/$A$/l, centre/$C$/c,
                             canr/$B$/r, canr/$B$/r, canr/$B$/r}
  \foreach \i [evaluate=\i as \j using int(\i+1)] in {1,2}{
    \tnbond[gauge]{(#1\i) -- (#1\j)}%
  }
  \foreach \i [evaluate=\i as \j using int(\i+1)] in {3,4,5}{
    \tnbond[gauge]{(#1\j) -- (#1\i)}%
  }
  \tnbond[gauge]{([xshift=-5mm]#11.west) -- (#11)}
  \tnbond[gauge]{([xshift=5mm]#16.east) -- (#16)}
  \tnlegs{#2}{#11-leg,#12-leg,#13-leg,#14-leg,#15-leg,#16-leg}%
}
